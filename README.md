## Базовые команды

| Команда | Что делает |
| --- | --- |
| `git init` | создаёт новый репозиторий в текущей папке |
| `git clone <url>` | скачивает удалённый репозиторий |
| `git status` | показывает изменённые файлы |
| `git add <файл>` | добавляет файл в индекс |
| `git commit -m "..."` | создаёт коммит |
| `git log --oneline` | краткая история коммитов |
| `git pull` | забирает изменения с сервера |
| `git push` | отправляет коммиты на сервер |

## Работа с ветками

```bash
git switch -c my-feature   # создать ветку и перейти в неё
git switch main            # вернуться на main
git merge my-feature       # влить ветку в текущую
git branch -d my-feature   # удалить ветку (локально)
git push origin -d my-feature  # удалить ветку (на сервере)
```

## Откат изменений

```bash
git restore <файл>        # отменить изменения в файле
git reset HEAD~1          # отменить последний коммит (сохранить изменения)
git revert HEAD           # создать новый коммит, отменяющий последний
```

## Сохранение незаконченной работы

```bash
git stash                 # сохранить незаконченные изменения
git stash pop             # восстановить сохранённые изменения
git stash list            # посмотреть список сохранений
```

## Просмотр истории

```bash
git log --oneline --graph --all   # красивая история коммитов
git diff                          # показать незаконченные изменения
git show <commit>                 # показать содержимое коммита
```

## Как отправить pull request

1. Форкните репозиторий (кнопка **Fork**).
2. Склонируйте форк к себе: `git clone <url>`.
3. Создайте ветку под изменение.
4. Внесите правку, закоммитьте, запушьте ветку.
5. Откройте pull request и опишите, что поменяли.

## Настройка Git

```bash
git config --global user.name "Ваше имя"
git config --global user.email "email@example.com"
git config --list                    # посмотреть все настройки
```

## Работа с удалённым репозиторием

```bash
git remote -v                 # посмотреть удалённые репозитории
git remote add origin <url>   # добавить удалённый репозиторий
git fetch origin              # получить обновления (не сливая)
git pull origin main          # получить и слить обновления
git push origin main          # отправить ветку на сервер
```

## Типичные workflows

### Feature Branch Workflow
```bash
git checkout -b feature/login        # создать ветку фичи
# ... вносите изменения ...
git add .
git commit -m "Add login feature"
git push origin feature/login        # отправить ветку
# Затем создать PR на GitHub
```

### Исправление ошибок в коммитах
```bash
git commit --amend           # изменить последний коммит
git rebase -i HEAD~3         # переписать последние 3 коммита
```

## Полезные советы

- **Перед push** — всегда проверьте: `git status`, `git log --oneline -5`
- **Хорошие коммит-сообщения** — пишите понятные описания в повелительном наклонении
- **Синхронизация** — регулярно делайте `git pull` перед началом работы
- **Отдельные ветки** — создавайте отдельную ветку для каждой задачи/фичи
- **gitignore** — не забывайте добавлять файлы в `.gitignore` (зависимости, конфиги, etc.)
