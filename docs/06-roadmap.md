# 06. Дорожная карта

| Этап | Содержание | Результат |
|---|---|---|
| 0. Документы | Бриф, требования, архитектура, юридика, чек-лист | Эта папка `docs/` |
| 1. Интеграции | Получить доступы к Агбис и Sipuni, изучить API | Подтверждённая схема импорта |
| 2. Каркас | Проект Django, модели, роли, аудит, Docker | Запускаемое приложение |
| 3. Импорт и метрики | Синхронизация из Агбис, расчёт метрик и ЦА | Заполненные карточки |
| 4. Звонки | Webhook Sipuni, всплывающая карточка, click-to-call | Рабочий колл-центр |
| 5. Сегменты и кампании | Конструктор, очередь обзвона, отчёт, выгрузка с аудитом | Обзвон по акциям |
| 6. Сервер | Деплой в РФ, HTTPS, бэкапы, мониторинг | Боевая среда |
| 7. Пилот и запуск | Обучение, пилот 1–2 недели, правки | Запуск |
| 8. После MVP | amoCRM, задачи, дашборд | Развитие |

3. Правила ЦА от заказчика.

5. Статус оператора ПД, формы согласий.
