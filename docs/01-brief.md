# 01. Бриф

## Цель
Рабочее место менеджера колл-центра для прачечной/химчистки: при входящем и исходящем звонке автоматически показывается вся информация о клиенте, а для акций можно собирать сегменты клиентов и обзванивать их.
Аналог модуля «колл-центр» из Агбис.

## Пользователи
- Менеджеры продаж: 3–4 человека в смену.
- Руководитель (заказчик): сегменты, выгрузки, отчёты.
- Разработка: Claude (код, документация, развёртывание).

## Существующие системы
- **Агбис**: основная учётная система химчистки (клиенты, заказы). Источник истории заказов.
- **Sipuni**: телефония (события звонков, click-to-call).
- **amoCRM**: источник данных по заявкам/сделкам (приоритет ниже MVP).

## Ключевые сценарии
1. Входящий звонок: карточка клиента открывается автоматически по номеру.
2. Исходящий звонок: из карточки или списка обзвона, карточка уже открыта.
3. Руководитель собирает сегмент (например, «не были 90+ дней, средний чек > X») и запускает кампанию обзвона с текстом акции.
4. По итогам звонка менеджер ставит результат; отказавшиеся больше не попадают в обзвоны.

## Принципы
- Просто пользоваться: минимум кликов, один экран на звонок.
- Законно: требования РФ заложены в архитектуру с первого дня.
- Агбис остаётся источником истины по заказам; мы читаем из него, а не заменяем.

## Критерии успеха MVP
- Карточка открывается менее чем за 2 секунды после начала звонка.
- Менеджер видит историю заказов, суммы, периодичность и ЦА без перехода в Агбис.
- Сегмент можно собрать и запустить в обзвон без помощи разработчика.
- Система развёрнута на сервере в РФ, с бэкапами.
