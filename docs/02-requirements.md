# 02. Требования

## MVP

### Карточка клиента
- ФИО, телефоны, адрес, источник, согласия.
- История заказов: дата, состав (категории вещей), сумма, статус.
- Метрики: число заказов, общая сумма, средний чек, дата последнего заказа, периодичность (средний интервал между заказами), ожидаемая дата следующего заказа.
- ЦА и теги: «разовый», «постоянный», «спящий», «VIP», по видам услуг (ковры, шторы, кожа и т. д.).
- История звонков и комментарии.
- Итог звонка: договорились, перезвонить, не дозвонились, отказ, «не звонить».

### Телефония (Sipuni)
- Входящий: webhook, поиск клиента по номеру, всплывающая карточка у менеджера (WebSocket). Нет клиента: создать нового.
- Исходящий: click-to-call через API.
- Журнал звонков: направление, время, длительность, менеджер, ссылка на запись (если есть).

### Сегменты и кампании обзвона
- Конструктор фильтров: давность заказа, сумма, средний чек, число заказов, категория услуг, ЦА/теги, просроченная периодичность, согласие на рекламу.
- Сохранённые сегменты, предпросмотр количества клиентов.
- Кампания: сегмент + название + текст акции/скрипт + период. Превращается в очередь обзвона.
- Менеджер видит следующего клиента, звонит, ставит итог.
- Отчёт по кампании: дозвонились, согласились, отказались.
- Выгрузка в CSV/Excel: только роль с правом выгрузки, каждая выгрузка пишется в журнал.
- Клиенты с «не звонить» или без согласия автоматически исключаются.

### Синхронизация
- Периодический импорт клиентов и заказов из Агбис в локальную БД.
- Пересчёт метрик и ЦА после каждой синхронизации.

### Роли
- Менеджер: карточки, звонки, свои кампании.
- Руководитель: сегменты, кампании, выгрузки, отчёты.
- Админ: пользователи, настройки интеграций, журнал.

## После MVP (бэклог)
- Интеграция с amoCRM (контакты, сделки, источники).
- Задачи и напоминания «перезвонить».
- Дашборд руководителя.
- SMS/мессенджеры.
- Оценка качества звонков.

## Нефункциональные требования
- Хостинг в РФ, HTTPS, ежедневные бэкапы с проверкой восстановления.
- Журнал действий (аудит).
- Отклик карточки менее 2 секунд.
- Рассчитано на 3–4 одновременных пользователя и десятки тысяч клиентов.
