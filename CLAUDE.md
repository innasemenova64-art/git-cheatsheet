# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**git-cheatsheet** — это образовательный проект: шпаргалка по Git и GitHub для начинающих разработчиков. Проект на русском языке и служит учебным материалом, на котором удобно практиковать создание pull request-ов.

Основной файл: `README.md` — содержит все команды Git и GitHub, организованные по разделам.

## Content Structure

Шпаргалка организована следующим образом:

1. **Базовые команды** — самые важные команды для новичков (init, clone, status, add, commit, log, pull, push)
2. **Работа с ветками** — создание, переключение, слияние, удаление веток
3. **Откат изменений** — способы отменить изменения (restore, reset, revert)
4. **Сохранение незаконченной работы** — команды stash
5. **Просмотр истории** — log, diff, show
6. **Настройка Git** — конфигурация user.name, user.email
7. **Работа с удалённым репозиторием** — remote, fetch, pull, push
8. **Типичные workflows** — Feature Branch и rebase workflows
9. **Полезные советы** — best practices для разработчиков

## Guidelines for Contributing

При добавлении новых разделов или команд:

- **Простота для новичков** — объяснения должны быть доступны для людей, которые только начинают изучать Git
- **Практичность** — показывайте реальные примеры использования, которые применяются в повседневной работе
- **Структурированность** — используйте таблицы для базовых команд и code blocks для примеров
- **Русский язык** — весь контент на русском языке для целевой аудитории
- **Не дублируйте** — проверяйте, что команда/концепция ещё не упомянута в другом разделе

## Common Tasks

- **Добавить новый раздел команд** — добавьте заголовок (##) и примеры в README.md
- **Обновить примеры** — убедитесь, что примеры актуальны и работают
- **Улучшить объяснения** — сделайте описания более ясными для новичков
- **Исправить ошибки** — проверьте синтаксис команд и точность информации

## Workflow for Pull Requests

Этот проект используется как учебная площадка для практики с PR-ами. При работе с PR-ами:

1. Создавайте feature branch для каждого изменения
2. Пишите понятные commit-сообщения на русском языке
3. В описании PR объясняйте, что было добавлено/изменено и почему
4. Проверьте, что изменения понятны для новичков
